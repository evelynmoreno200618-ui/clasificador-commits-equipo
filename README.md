# Clasificador de Commits

Proyecto desarrollado por el equipo Evelyn.

## Descripción

Este proyecto busca implementar una solución de Inteligencia Artificial para clasificar commits de un repositorio.

## Herramientas

- Git
- GitHub
- Ollama
- Bash
- Markdown

## Configuración

Para configurar el entorno se utiliza el archivo `Setup.sh`.

También se incluye el archivo `Ollama.tar.zst` relacionado con la configuración de Ollama.

## Documentación

La documentación técnica del proyecto se encuentra en los archivos correspondientes del repositorio.
